## ✨ What is Linux-Goodies?

**Linux-Goodies** is a lightweight, interactive shell script designed to supercharge your Linux terminal experience. Featuring smooth arrow-key navigation with full background highlighting, it automates package installations, sets up cool terminal utilities, and lets you customize your aesthetic on the fly!
